# Python Game of Life

Небольшой проект на Python с реализацией клеточного автомата «Игра в жизнь» Джона Конвея.

## О проекте

Поле состоит из клеток, каждая из которых может быть живой или мёртвой. На каждом шаге состояние клетки определяется количеством её живых соседей:

- живая клетка с двумя или тремя соседями остаётся живой;
- мёртвая клетка с тремя соседями становится живой;
- во всех остальных случаях клетка погибает или остаётся мёртвой.

Из этих простых правил возникают устойчивые фигуры, осцилляторы и движущиеся структуры.
