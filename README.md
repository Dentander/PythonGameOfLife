# Python Game of Life

Небольшой проект на Python с реализацией клеточного автомата «Игра в жизнь» Джона Конвея.

## О проекте

Поле состоит из клеток, каждая из которых может быть живой или мёртвой. На каждом шаге состояние клетки определяется количеством её живых соседей:

- живая клетка с двумя или тремя соседями остаётся живой;
- мёртвая клетка с тремя соседями становится живой;
- во всех остальных случаях клетка погибает или остаётся мёртвой.

Из этих простых правил возникают устойчивые фигуры, осцилляторы и движущиеся структуры.

## Запуск

Нужен Python 3.10+ и библиотека Pygame:

```bash
pip install pygame
python main.py
```

После запуска откроется окно симуляции размером 1000 × 600.

## Управление

| Действие | Управление |
| --- | --- |
| Перемещение по полю | `W`, `A`, `S`, `D` или перетаскивание правой кнопкой мыши |
| Масштаб | Колесо мыши |

Симуляция запускается со случайно заполненным полем. Параметры окна, скорости и масштаба находятся в `config.py`.

## Структура

- `main.py` — окно Pygame, обработка ввода и логика клеточного автомата;
- `config.py` — настройки экрана, симуляции и цветов.
